ASMA CLOCK - Android exact prayer adhan

WHAT THIS BUILD IS
The clock UI is still the web app. On launch you get a native test screen.
That screen still schedules one exact notification one minute from now.
After you tap "Open Asma Clock", the web app sends Fajr, Dhuhr, Asr, Maghrib
and Isha times to the phone. Android then fires those times with
setExactAndAllowWhileIdle even if the app is closed, and plays the matching
included adhan to the end (a foreground service, not a 1-minute cap).

HOW TO GET THE APK
This PC does not use Android Studio. Build in GitHub Actions:
1. Push this repo (or run the workflow "Android debug APK" by hand).
2. Open the workflow run. Download the artifact asma-clock-debug.
3. Install the APK on a phone (allow unknown sources). Debug APKs are unsigned.

HOW TO TEST
1. Open Asma Clock. You should see "Exact alarm test".
2. Tap "Notify in 1 minute". Allow notifications if Android asks. On some phones
   you must also allow exact alarms, then tap the button again.
3. Leave the app or lock the phone. After about one minute a notification should
   appear and the Maghrib/Isha adhan file should play through.
4. Tap "Open Asma Clock". In Settings, tap "Allow alerts while idle" and grant
   notifications, exact alarms, and turning off battery optimisation.
5. Check the next prayer time on the Prayer page. Leave the app or lock the
   phone before that time. The included adhan for that slot should start at
   the scheduled minute and run to the end (several minutes).
6. Turn a prayer off on the Routine page: that slot should not fire.
7. Set Adhan sound to Silent: native prayer alarms should be cancelled.
8. Reboot the phone: the saved next times should be restored (open the app once
   after install so times are saved first).

If the notification is late or missing, note the phone brand and Android version.
Tecno, Infinix and Xiaomi often kill background work unless battery saving is
off for this app.

REBUILDING
From the repo root: npm ci && npx cap sync android
Then in android/: ./gradlew assembleDebug
Do not edit android/app/src/main/assets/public by hand. It is copied from web/.
