# Asma Clock

Analog clock with the 99 Names of Allah, prayer times, Hijri calendar, routine planner, and (soon) Learn, Roots and games. English, French, Arabic.

See docs/PROJECT.md for the full guide.

Quick start
- Web: open web/index.html through any static server (for example `npx serve web`).
- Windows: `cd desktop && npm install && npm start`
